Model Parameters

These parameters control how the RMAB model learns and generates recommendations.

Parameter Value Description
Number of Clusters {{ config.N_CLUSTERS }} Number of caregiver behavior clusters
Discount Factor (γ) {{ config.GAMMA }} Future reward discount (0-1, closer to 1 = more forward-looking)
Alpha (Dirichlet) {{ config.ALPHA }} Prior strength for Bayesian estimation
Min Observations {{ config.MIN_OBSERVATIONS }} Minimum observations required per cluster
Random State {{ config.RANDOM_STATE }} Seed for reproducibility (null = random)

How to Update Settings

To change these settings, update your .env file and restart the server: 

# Example .env file
N_CLUSTERS=20
GAMMA=0.99
ALPHA=1.0
MIN_OBSERVATIONS=10
REQUIRE_AUTH=false
LOG_LEVEL=INFO

Note: Settings are loaded at startup. After changing the .env file, you must restart the server for changes to take effect.

Advanced Configuration

Model Tuning Guide

Number of Clusters (N_CLUSTERS)
Higher values create more fine-grained caregiver groups but may overfit on sparse data. Lower values create broader groups but may miss important behavioral differences. Recommended range: 10-30 for datasets with 1000+ caregivers.
Discount Factor (GAMMA)
Controls how much the model values future engagement vs. immediate results. Values closer to 1.0 prioritize long-term retention. Recommended range: 0.90-0.99
Alpha (Dirichlet Prior)
Controls how much weight to give to the prior vs. observed data. Higher values make the model more conservative (trust the prior more). Recommended range: 0.5-2.0
Min Observations
Minimum number of state transitions required to estimate cluster parameters. Higher values require more data but give more reliable estimates. Recommended range: 5-20
